    About this site

    COMP3612 Shop is a single-page application for browsing a catalogue of 100 products. You can filter and sort the catalogue, look at one product in detail, and manage a shopping cart that is still there the next time you visit. Every view lives in one HTML page; JavaScript shows and hides them.

    Technologies

    • HTML5
    • CSS3 (no framework)
    • JavaScript modules
    • fetch API
    • localStorage
